# Нейро-змейка - план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** змейка на двоих 32x32, где правила мира выполняет своя свёрточная сеть на numpy, а соперник - своя сеть, обученная подражанием и пробами.

**Architecture:** пакеты `nn` (слои), `teacher` (правила, только обучение), `world` (кодировка и сеть-мир), `player` (бот и сеть соперника), `train` (обучение, запись в `models/`), `game` (окно на Qt). Игра импортирует только `nn`, `world`, `player`, `game`. Спек: `docs/superpowers/specs/2026-09-26-snake-ai-design.md`.

**Tech Stack:** Python 3.13, numpy, PySide6, pytest, PyInstaller, NSIS.

Выполняет план Claude в той же сессии (Алексей: «без остановок»), поэтому код каждого шага
пишется при выполнении по интерфейсам и тестам ниже; на каждый шаг - сначала красный тест.

---

## Общие соглашения

- Направления: `UP=0, DOWN=1, LEFT=2, RIGHT=3, NONE=4`; сдвиги `DELTA = [(-1,0),(1,0),(0,-1),(0,1)]` как (строка, столбец).
- Поле - `np.ndarray (H, W) int8` с классами 0..11 из спека п. 4.
- Все сети в float32. Раскладка тензоров `(B, H, W, C)`.
- Команда тестов: `python -m pytest -q` из корня.

## Task 2: nn - слои с проверкой градиентов

**Files:** `nn/layers.py`, `nn/optim.py`, `nn/io.py`, `tests/test_nn.py`.

Интерфейс слоя: `forward(x) -> y`, `backward(dy) -> dx`, `params() -> list[(name, array, grad)]`.
Слои: `Conv3x3(cin, cout)` (паддинг нулями, im2col через `sliding_window_view`),
`Conv1x1(cin, cout)`, `ReLU`, `Dense(nin, nout)`, `GlobalMax` (`(B,H,W,C)->(B,C)`, градиент
в клетку максимума). `Adam(params, lr)`. `save(path, dict_of_arrays)`, `load(path)`.
Функции потерь: `softmax_xent(logits, target, weight)` по последней оси, `bce(logits, target)`.

Тесты (все красные до реализации):
- численный градиент (центральная разность в float64) совпадает с `backward` до 1e-4 для
  каждого слоя и для обеих потерь;
- `Conv3x3` на поле 1x1 с ядром-единицей в центре = `Conv1x1`;
- `GlobalMax` отдаёт градиент только в клетку максимума;
- Adam уменьшает квадратичную функцию за 200 шагов в 100 раз;
- `save`/`load` возвращает те же массивы.

## Task 3: teacher - правила

**Files:** `teacher/rules.py`, `teacher/start.py`, `tests/test_teacher.py`.

- `step(field, a1, a2, rng) -> Outcome(field, ate=(b,b), crashed=(b,b), food=(r,c)|None)`;
  при столкновении `field` = None.
- `heading(field, snake) -> dir`, `head(field, snake) -> (r,c)`, `cells(field, snake) -> list`.
- `start_field(h=32, w=32)`: змейка 1 длины 3 слева головой вправо, змейка 2 справа головой
  влево, еда в центре. Лежит в `world/start.py` (данные, нужны игре), `teacher` его
  переиспользует.
- `grow_random(field, snake, length, rng)` - случайное блуждание для разнообразных полей.

Тесты: движение вперёд; `NONE` и разворот = прежнее направление; край; тело; свой хвост
(врезалась); чужая голова; лоб в лоб в одну клетку - обе; обмен головами - обе; рост при
еде (длина +1, хвост на месте); еда только в пустой клетке (1000 розыгрышей); указатели
тела после хода ведут от хвоста к голове; стартовое поле корректно.

## Task 4: world - кодировка и сеть-мир

**Files:** `world/encode.py`, `world/net.py`, `world/start.py`, `tests/test_world_encode.py`, `tests/test_world_net.py`.

- `encode(fields (B,H,W), a1 (B,), a2 (B,)) -> (B,H,W,23) float32`.
- `WorldNet`: слои по спеку п. 6; `forward(x) -> (cell_logits (B,H,W,12), food_logits (B,H,W), event_logits (B,4))`; `backward(...)`; `save/load`.
- `WorldNet.step(field, a1, a2, rng) -> Result(field|None, ate, crashed, food_probs, confidence)`:
  argmax классов; события сигмоида > 0.5; при съедании клетка еды - выбор из softmax
  карты еды (`rng.choice`).

Тесты: кодировка - одна единица на клетку, ходы по всему полю; сеть работает на полях
разного размера; градиенты всей сети численно (маленькое поле); `step` детерминирован при
одном сиде; исходники `world/` и `game/` не содержат `teacher`.

## Task 5: данные и обучение сети-мира

**Files:** `teacher/data.py`, `train/world_train.py`, `tests/test_world_data.py`, `tests/test_world_trained.py`, `models/world.npz`, `models/world.json`.

- `teacher.data.batch(rng, n, size_range)` -> входы, цели классов, веса клеток, маска
  столкновения, цели событий, цель еды, маска еды. Смесь: партии ботов с шумом 0-50% и
  поля с выращенными змейками.
- `python -m train.world_train --steps N` - Adam, поля 8-16, в конце 32; каждые K шагов
  точность на отложенных 32x32; паспорт `models/world.json` (точности, кривая потерь).

Тесты данных: веса больше у меняющихся клеток; маска поля 0 на ходах со столкновением.
Тесты обученной сети (`models/world.npz`): п. 6 спека - поле целиком ≥ 99.5%, события ≥
99.9%, еда на занятых < 1%; змейка длины 100+ идёт 50 ходов без ошибки; 300 ходов
«сеть против учителя» из старта с ботами.

## Task 6: соперник

**Files:** `player/view.py`, `player/bot.py`, `player/net.py`, `train/player_train.py`, `tests/test_player.py`, `models/player_*.npz`, `models/player.json`.

- `view(field, snake) -> (906,) float32`; `bot_move(field, snake) -> dir`;
  `PlayerNet.act(field, snake, greedy=True) -> dir`.
- Обучение: подражание (снимок «новичок» рано, «средний» в конце), REINFORCE → «сильный»,
  принимается только если не хуже «среднего» против бота.

Тесты: окно у края - край как препятствие; бот не врезается, если есть безопасный ход;
бот идёт к еде кратчайшим путём; сеть «средний» выигрывает у случайного ≥ 90% раундов;
«сильный» не хуже «среднего» против бота.
