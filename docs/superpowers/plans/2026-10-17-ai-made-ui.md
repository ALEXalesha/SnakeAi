# SnakeAi 2.0: окно и картинку делают нейросети - план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** раскладку окна выдаёт своя сеть-дизайнер, клетки поля рисует своя сеть-художник; законы проверяют их ответ, при провале - пересэмплирование и запасной вариант кода с записью в журнал.

**Architecture:** нынешние Qt-раскладки экранов остаются учителем и запасным вариантом: в режиме ИИ верхние раскладки экрана выключаются (`QLayout.setEnabled(False)`), и каждый элемент из списка экрана получает `setGeometry` из ответа сети. Поле рисуется из тайлов 24x24 по «ключу клетки» (вид, змейка, связи с соседями, место в змейке, чётность, авария); тайлы для набора шума партии считает сеть-художник одним пакетом, кадр собирается numpy из тайлов. Учителя для обеих сетей - код в `game/ui` (раскладка Qt и рисование тайла QPainter), он же запасной.

**Tech Stack:** Python 3.13, numpy (свои слои `aikit.nn`), PySide6 6.11, pytest offscreen. Без PyTorch и pygame.

**Spec:** `docs/superpowers/specs/2026-10-17-ai-made-ui-design.md`

## Global Constraints

- Сети свои и маленькие, numpy (`aikit.nn.layers.Dense`, `ReLU`, `aikit.nn.optim.Adam`, `aikit.nn.io`); PyTorch и внешний ИИ нельзя.
- Виджеты остаются настоящими Qt-виджетами - всё нажимается, клавиши и фокус как в 1.1.0.
- Законы раскладки: всё внутри окна/родителя, соседи не налезают, текст читается (контраст, размер не меньше `minimumSizeHint`, у переносимых меток `heightForWidth(w) <= h`), кнопки не меньше 28 px в высоту, поле целиком видно (квадрат поля >= 320 px).
- Законы поля: у каждого тайла сети - тот же вид клетки по ближайшему кодовому тайлу (пусто/еда/тело/голова/хвост и змейка), среднее отличие от кодового тайла <= порога из паспорта.
- Не прошло - до 3 пересэмплирований шума, потом код; событие тихо пишется в `ctx.data_dir/ai_ui.json`.
- Раскладка считается раз на (экран, размер, тема, язык, видимость, шум); художник - раз на (палитра, шум партии); кадр не медленнее 1.1.0.
- Новая версия заменяет обычную, переключателя «как раньше» нет. Версия 2.0.0 в `game/version.py` и `installer.nsi`.
- «Настройки» растягиваются на всё окно, как «Статистика» (жалоба Алексея: прижаты в левый верхний угол).
- Тесты только offscreen, без видимых окон. Закон «нет кода правил»: `game/core`, `game/ai`, `game/ui`, `game/design`, `main.py` не импортируют `game.teacher` и `game.train`.
- Тексты RU+EN (тест одинаковых ключей), дефис вместо тире.

## Review Focus

- Окно на настоящем экране Алексея: шрифты чуть шире offscreen, метка просит лишнюю строку - законы должны поймать и взять код, а не обрезать текст (тест с шрифтом +10%, Task 7).
- Окно больше обученного (4K, 3840x2160) и минимальное 820x600 - раскладка в законах или запасная (Task 6/7).
- Смена языка/темы и появление сообщения об ошибке в меню посреди режима ИИ - раскладка пересчитывается, ничего не налезает (Task 7).
- Разорванная змейка (сбой сети-мира) и змейка длины 1 - у художника нет такого ключа в обучении; тайл сети с проверкой, иначе кодовый (Task 4/5).
- Битые или пропавшие designer.npz/painter.npz - игра идёт на коде, в журнале причина, окно не падает (Task 7).
