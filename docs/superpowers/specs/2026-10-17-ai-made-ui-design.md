# SnakeAi 2.0: окно и картинку делает ИИ - описание замысла

Дата: 17.10.2026. Описание - Claude по разговору с Алексеем. Статус: ждёт «да».

## Зачем
Идея Алексея: «весь интерфейс и вся игра полностью делается ИИ каждый раз, не прописан интерфейс, а ИИ сам его прописывает»;
«каждый раз она должна делать одно и то же, что сейчас делает код, но это ИИ, а значит будут отличия».
Правила игры уже ведёт своя сеть-мир (с 1.0.0, без кода правил). Остаётся то, что пока делает код: **окно** и **картинка поля**.

## Цели
1. **Сеть-дизайнер окна.** Своя маленькая сеть (numpy, как остальные сети игры) выдаёт раскладку окна: где поле, панели,
   кнопки, их размеры, шрифты, цвета, отступы - для текущего размера окна, темы и экрана (меню, матч, итоги, статистика,
   настройки). Учится на раскладках, которые сейчас делает код (много размеров окна и тем). Выход берётся с долей случайности -
   каждый запуск окно почти то же, но с отличиями. Виджеты остаются настоящими Qt-виджетами - всё нажимается.
2. **Сеть-художник поля.** Вместо кода рисования клеток - сеть, которая по классу клетки и её соседям (тело, голова, поворот,
   хвост, еда, пусто) рисует картинку клетки (например 20x20 RGB), с шумом на входе - «рука» каждый раз чуть разная.
   Учится на кадрах нынешнего рисования.
3. **Проверка и запасной вариант** (выбор Алексея): раскладка проверяется законами (всё внутри окна, ничего не налезает,
   текст читается - контраст, кнопки не меньше минимального размера, поле целиком видно); картинка поля - что змейку,
   еду и голову можно различить (сравнение со своим «правильным» кадром по классам клеток). Не прошло - пересэмплировать
   несколько раз, затем взять раскладку/рисунок кода как запасной и тихо записать в журнал.
4. **Вместо обычной** (выбор Алексея): новая версия заменяет кодовую; кодовая остаётся только учителем и запасным вариантом.

## Не цели
- Генерация новых правил или режимов - игра остаётся той же змейкой на двоих.
- Большие сети, PyTorch, внешний ИИ (выбор Алексея - своя маленькая сеть).

## Анти-цели
- Окно, которое иногда неиграбельно (кнопку не видно, поле обрезано).
- «Отличия», похожие на мусор: цель - узнаваемо та же игра, живая вариация.
- Тормоза: раскладка - раз при смене размера/экрана; художник - кэш по классам клеток, кадр не медленнее нынешнего.

## Решения Claude (можно поправить)
- Дизайнер: небольшая плотная сеть, вход - размер окна, экран, тема, шум; выход - прямоугольники и стили фиксированного
  списка элементов экрана. Художник: сеть 3x3-окрестность класса + шум → тайл клетки; тайлы кэшируются на набор шума партии.
- Новый пункт в «Статистике»: «Насколько окно отличается от кодового», «Сколько раз сработал запасной вариант».
- Версия 2.0.0; README объясняет: «правила, окно и картинку делают нейросети».

## Что остаётся строителю
Список элементов каждого экрана и формат раскладки, сбор обучающих данных (код раскладывает окно в offscreen на сотнях
размеров), архитектуры и обучение, законы проверки, мутанты, выпуск через release.ps1.
