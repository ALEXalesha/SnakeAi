**Neuro Snake 1.0.0 - two-player snake with no snake rules in the game.**

- **The world is a neural network.** Every tick the old field and both key presses go into a convolutional network written from scratch in numpy, and it returns the new field, who ate, who crashed and where the next food appears. The game only draws, keeps score and reads keys. The rules live in a teacher used only for training; it is not in the build, and a test checks that neither the game nor the world network imports it.
- **Exact.** A body cell stores a pointer to the neighbour closer to the head, so every rule is local and a network trained on short snakes carries long ones. One pass matches the rules on 99.8% of moves on held-out 32x32 fields; in the game the network looks at the field in all eight rotations and mirror images at once and adds the answers, which gives 100% of moves at about 22 ms per move.
- **An opponent network** sees a 15x15 window around its head and learned by imitating a path-finding bot, then by reinforcement against it. Three levels: novice, medium, strong.
- **A Qt window**: menu, matches to three points with a countdown and pause, statistics with both networks' training curves, settings (speed, opponent, volume, three palettes, a map of where the network would put food), synthesized sounds; the window reopens where it was closed.
- 161 tests.

Files: `SnakeAIGame-1.0.0-setup.exe` (installer, no admin rights) and `SnakeAIGame-1.0.0-portable.zip`. The builds are not code-signed, so SmartScreen may warn on first start.

**Нейро-змейка 1.0.0 - змейка на двоих без правил змейки в коде игры.** Каждый ход старое поле и два нажатия уходят в свою свёрточную нейросеть на numpy, и она выдаёт новое поле: кто съел, кто врезался, где родится еда. Игра только рисует, считает очки и читает клавиши; правила живут в «учителе» только для обучения, в сборку он не входит. Тело змейки хранит указатель на соседа ближе к голове - все правила местные, и сеть, обученная на коротких змейках, ведёт длинные. Один проход совпадает с правилами на 99,8% ходов; в игре сеть смотрит на поле в восьми поворотах и отражениях сразу и складывает ответы - 100% ходов, около 22 мс на ход. Против вас играет вторая сеть: подражание боту, потом пробы и ошибки, три уровня. Окно на Qt: меню, матч до трёх побед, статистика с графиками обучения, настройки, звуки. 161 тест.
