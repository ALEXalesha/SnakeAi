**Neuro Snake 2.0.0 - the window and the board are made by neural networks.**

- The rules were already a network; now a **designer network** lays out every screen (where each button, panel and label goes, the font size, corner radius and accent colour) and a **painter network** paints every board cell (body, turn, tail, head with eyes, food). Both learned from what the code of 1.x did and both take random noise, so every launch the window is almost the same, never identical.
- Laws check every answer: everything inside the window, nothing overlaps, every text has room and contrast, buttons at least 28 px, the board fully visible; painted tiles must be recognisable. On failure the game tries new noise, then quietly uses the code and logs it. Statistics show how far the window is from the coded one and how often the fallback was needed. In 240 launches over six window sizes from 820x600 to 4K it was needed zero times.
- Settings now fill the whole window in two cards, like Statistics.
- 313 tests.

Files: `SnakeAIGame-2.0.0-setup.exe` (installer, no admin rights) and `SnakeAIGame-2.0.0-portable.zip`. The builds are not code-signed, so SmartScreen may warn on first start.

**Нейро-змейка 2.0.0 - окно и поле рисуют нейросети.** Правила уже вела сеть-мир, теперь **сеть-дизайнер** раскладывает каждый экран (где кнопки, панели и подписи, размер шрифта, скругление, оттенок акцента), а **сеть-художник** рисует каждую клетку поля (тело, поворот, хвост, голову с глазами, еду). Обе учились на том, как это делал код 1.x, и обе получают случайный шум: каждый запуск окно почти то же, но не одно и то же. Каждый ответ проверяют законы: всё внутри окна, ничего не налезает, тексту хватает места и контраста, кнопки не ниже 28 px, поле видно целиком, клетки узнаются. Не прошло - новый шум, потом тихо код и запись в журнал; в «Статистике» видно, насколько окно отличается от кодового и сколько раз понадобился запасной вариант (на 240 запусках при шести размерах окна от 820x600 до 4K - ни разу). Настройки теперь на всё окно двумя карточками, как «Статистика». 313 тестов.
